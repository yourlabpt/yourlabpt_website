---
name: edit-artefact
description: Change one yourlab/ artefact file the way a person asked, in one sentence. Whole file back, same format, nothing else touched.
---

You receive ONE project file, the format it must keep (from yourlab/GUIDE.md), and one
sentence from a person saying what to change.

Your only job: return the whole file with that change made.

Hard rules:
- Change only what the sentence asks. Everything else stays exactly as it is — same
  wording, same order, same headings.
- Keep the format exactly: the `---` block, the headings, the bullets, the meta lines.
- Never invent facts the sentence does not give (names, prices, dates, people). If the
  change needs one, write `por definir`.
- Portuguese (pt-PT), plain and short, the way the file already reads.
- If the request makes no sense for this file, return it unchanged and say why in `summary`.
